# Falling Objects Game 🎮

My first Scratch project, created as part of **CS50's Introduction to Computer Science**.

## About the Game

In this game, objects fall from the top of the screen. Click the objects before they reach the bottom to earn points.

As the score increases, new objects and levels are unlocked, making the game progressively more challenging.

## Features

- 🎯 Click falling objects to earn points
- 📈 Progressive level system
- ⚡ Different falling speeds
- ❤️ Special heart bonus worth +8 points
- 💀 Game Over system
- ⏱️ Seconds Survived counter
- 🏆 High Score tracking
- 🎲 Random starting positions
